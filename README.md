# 로또 발매기

## 구현할 기능 목록

### 입력
- [x] 구입금액을 입력받는다.
- [x] 당첨 번호를 입력받는다.
- [x] 보너스 번호를 입력받는다.

### 출력
- [x] 구입금액에 대한 안내문 출력.
- [x] 구입금액에 따른 로또 구매 개수 출력.
- [x] 당첨 번호 입력에 대한 안내문 출력.
- [x] 보너스 번호 입력에 대한 안내문 출력.
- [ ] 당첨 통계를 출력.
- [ ] 수익률 출력.

### 파싱
- [x] 당첨번호를 파싱한다.
- [x] 보너스 번호를 파싱한다.
- [x] 구입금액을 파싱한다.

### 로또 게임 (LottoGame)
- [x] 로또 구입 금액을 입력받는다.
- [x] 로또 발매기로부터 로또들을 발급받는다.
- [x] 발급받은 로또의 수와 그 숫자들을 출력한다.
- [x] 로또 당첨 번호와 보너스 번호를 입력받아 저장한다.
- [x] 각 입력이 예외를 던질 때, 다시 입력으로 돌아가게 한다.
- [ ] 로또 번호 비교기를 통해 결과를 받는다.
- [ ] 당첨 내역을 출력한다.
- [ ] 수익률을 출력한다.


### 로또발매기 (LottoGenerator)
- [x] 로또를 n개 산다.
  - 로또를 n번 발급한다.
- [x] 로또 번호 6개를 발급받는다.

### 로또 번호 비교기 (LottoChecker)
- [ ] 로또와 당첨번호+보너스번호가 얼마나 일치하는지 확인한다.
- [ ] 수익률을 계산한다.

### 로또 (Lotto)


### 로또 등수 (LottoRank)
- [ ] 로또 등수에 따른 일치 횟수와 상금 enum 반환.

### 랜덤 (Random)
- [x] 1~45 사이의 랜덤 숫자가 포함된 리스트를 반환.

### 당첨통계 (LottoAnalyzer)
- [ ] 1~5등 개수 저장.

### 예외 처리 목록
- [x] 구매 금액이 1000단위가 아닌 경우.
- [x] 구매 금액이 숫자가 아닌 경우.
- [x] 당첨 번호가 6개가 아닌 경우.
- [x] 당첨 번호가 콤마(,)로 구분되지 않는 경우.
- [x] 당첨 번호에 공백이 포함된 경우.
- [x] 당첨 번호 각각이 숫자가 아닌 경우.
- [x] 보너스 번호가 숫자가 아닌 경우.
- [x] 당첨 번호 및 보너스 번호가 1부터 45 사이의 숫자가 아닌 경우.
